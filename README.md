## 🚀 Проекты

### FormCraft — конструктор онлайн-форм
SPA для сборки форм через drag-and-drop с шарингом по ссылке и сбором откликов. Архитектура по Feature-Sliced Design, разделение серверного и клиентского состояния, типобезопасная валидация через Zod, тесты по TDD. Оптимизация загрузки через lazy — тяжёлые модули подгружаются по требованию.

`React` · `TypeScript` · `TanStack Query` · `Zustand` · `Zod` · `dnd-kit` · `Tailwind` · `Vitest`

🔗 [Репозиторий](https://github.com/nikidanil/craftform-app)

### Hotel Booking — система бронирования
Fullstack-приложение бронирования номеров: каталог, бронирование по датам, ролевая модель доступа (гость / пользователь / админ), админ-панель. Собственный REST API на Node.js, авторизация на JWT, проверка доступности с двойной валидацией. Контейнеризация в Docker и деплой на VPS.

`React` · `Redux Toolkit` · `Node.js` · `Express` · `MongoDB` · `JWT` · `Docker`

🔗 [Репозиторий](https://github.com/nikidanil/booking-app)

### Notes — заметки в стиле macOS
Приложение заметок с авторизацией, Markdown-разметкой и подсветкой кода. Работа с Firebase как бэкендом, кастомный хук автосохранения с debounce, управление сложным состоянием через useReducer.

`React` · `TypeScript` · `Firebase` · `useReducer` · `Markdown`

🔗 [Репозиторий](https://github.com/nikidanil/notes-mac-app)
